# Data Contract Schema & OpenAPI Spec Generator

Form-driven OpenAPI 3.1 YAML stub generator — define fields via a dynamic form and export a complete paths + components/schemas spec.

## Key Features

- Add up to 20 fields with name, type (string/integer/number/boolean/array/object), format, required toggle, and description
- Generates a full OpenAPI 3.1 YAML stub with GET/POST/PUT/DELETE paths, requestBody, and responses
- One-click clipboard copy of the generated YAML
- localStorage persistence of field list and schema metadata across sessions
- Mobile-responsive layout with per-field type-aware format dropdowns
